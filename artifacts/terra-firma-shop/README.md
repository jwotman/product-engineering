## What this package is meant to prove

Terra Firma is not presented as “an AI art project.”

The project combines:

- market/category selection;
- geospatial data;
- deterministic rendering;
- selective generative visual treatment;
- production QA;
- e-commerce content and merchandising;
- Shopify theme work;
- browser/mobile verification;
- multi-agent production operations.

The recurring product rule is:

> **Automate repeatable work, keep source truth inspectable, and reserve judgment for the places where judgment is the product.**

## Evidence posture

The private repository contains both implemented systems and planning artifacts.

The public package distinguishes those carefully.

For example:
- the render pipeline and QA skills are implemented;
- multi-agent production infrastructure has both implemented pieces and planned extensions;
- Terra Firma remains pre-launch, so launch operations are not presented as post-launch production history.
